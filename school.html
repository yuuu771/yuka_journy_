ニューヨークでコミュニティカレッジに通い始めた話

September 2026

ニューヨークで生活する中で、コンピュータサイエンスを きちんと学んでみたいと思うようになり、 コミュニティカレッジに通い始めました。

日本では英米文学を専攻していたので、 コンピュータサイエンスはまったく違う分野。 プログラミングもほぼ初心者で、 数学を最後にしっかり勉強したのは 就職活動のSPI対策をしていた頃でした。 もう10年くらい前のことです。

入学前は、楽しみと不安が半分ずつ

授業についていけるのか心配な一方で、 今まで知らなかったことを一から学べるのは 楽しみでもありました。

実際に通ってみて感じたこと

高校を卒業してそのまま進学してきたくらいの 年齢の学生が多い一方で、 年上の学生や年配の方もちらほら。

思っていたよりも幅広い年代の人が 通っているのが印象的でした。

コンピュータサイエンスの授業

コミカレではC++やJavaを使いながら、 変数、条件分岐、ループ、関数、 データ構造などを少しずつ学びました。

最初はコードを読むだけでも時間がかかりましたが、 少しずつ「このコードが何をしているのか」が 分かるようになってきました。 

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, New York!" << endl;
    return 0;
}

こういった短いコードから始めて、 少しずつ長いプログラムを書くようになりました。

これから書いていきたいこと

最初は授業登録やクラス選び、 課題の提出方法など、 分からないこともたくさんありました。

これからこのブログでは、 コミュニティカレッジの授業や学校の雰囲気、 授業登録、コンピュータサイエンスの勉強について、 実際に経験したことを少しずつ残していこうと思います。
